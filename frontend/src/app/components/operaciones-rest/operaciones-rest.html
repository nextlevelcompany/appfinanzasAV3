# Nombre del Formulario Enfoque Angular Módulo Angular Campos y Validaciones Operación Invocada Ubicación
1 Iniciar Sesión (Login) Template-driven FormsModule (ngForm, ngModel) Username (required), Password (required) POST /auth/login Vista /login
2 Registro de Usuario Reactivo ReactiveFormsModule (FormBuilder) Username (min 3, max 80), Password (min 8), Confirmación coincidente POST /auth/register Vista /login
3 Registrar Cuenta Financiera Reactivo ReactiveFormsModule (FormGroup) Nombre (min 3), Tipo (select), Moneda (select), Saldo (min 0) POST /api/cuentas Vista /cuentas
4 Modificar / Actualizar Cuenta Template-driven FormsModule (ngForm, ngModel) ID (hidden/disabled), Nombre (min 3), Tipo, Moneda, Saldo >= 0 PUT /api/cuentas/{id} Vista /cuentas
5 Registrar Transacción Reactivo ReactiveFormsModule (FormGroup) Descripción (min 3), Monto (> 0), Tipo (radio), Categoría, Fecha POST /api/transacciones Vista /transacciones
6 Filtro por Rango de Fechas Template-driven FormsModule (ngForm) Fecha Desde (required), Fecha Hasta (required, >= Desde) GET /api/transacciones/rango Vista /transacciones
7 Filtro por Tipo y Categoría Reactivo ReactiveFormsModule (FormGroup) Tipo (select: TODOS, INGRESO, GASTO), Categoría (texto) GET /api/transacciones/tipo & /categoria Vista /transacciones
8 Registrar Categoría Template-driven FormsModule (ngForm) Nombre de categoría (min 2), Tipo (INGRESO o GASTO) POST /api/cuentas/categorias Vista /categorias
